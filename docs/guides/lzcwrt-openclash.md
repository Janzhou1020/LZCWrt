# iStoreOS安装插件

## 前言

> 这里采用的是 iStoreOS + openclash 方案
>
> 为什么采用此方案？iStoreOS可以通过社区提供的run包一件安装插件，非常方便

## 1.下载插件

[下载插件]([bcseputetto/Are-u-ok: KoolCenter iStore .run Packages](https://github.com/bcseputetto/Are-u-ok))

在下载时，请根据您当前系统的版本来选择对应插件，这里使用的是LZCWrt内置的 **iStoreOS 24.10.6** 版本

![image-20260506163925060](./img/image-20260506163925060.png)

![image-20260506164029747](./img/image-20260506164029747.png)

请根据当前系统的平台来选择下载的版本，可以用ssh连接上微服后用 `uname -m` 命令查看平台架构

![image-20260506164224693](./img/image-20260506164224693.png)

可以看到当前平台是x86_64，所以我们选择x86_64平台下载

![image-20260506164047087](./img/image-20260506164047087.png)
